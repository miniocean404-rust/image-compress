# NAPI-RS Skill

使用 Rust 构建高性能 Node.js 原生扩展的专家助手。

## 功能特性

- **项目初始化** - 使用 @napi-rs/cli 快速创建项目
- **导出机制** - 函数、类、常量、枚举的导出
- **类定义** - 构造函数、方法、Getter/Setter、工厂方法
- **异步函数** - Tokio 集成和 Promise 转换
- **多线程回调** - ThreadsafeFunction 跨线程调用
- **数据传递** - Object 类型和克隆行为
- **跨平台构建** - 多平台二进制包分发策略

## 触发场景

- 创建或修改 NAPI-RS 项目
- 使用 `#[napi]` 宏导出 Rust 代码
- 实现异步函数和 Tokio 集成
- 处理多线程回调
- 配置跨平台构建

## 关键词

napi-rs, napi, node addon, rust binding, #[napi], ThreadsafeFunction, tokio async, node.js native, cross-platform build, napi-derive

## 使用方法

当遇到 NAPI-RS 相关任务时，此 skill 会自动激活，提供：

1. 代码模式和最佳实践
2. 类型安全的 Rust-JavaScript 绑定
3. 异步函数和多线程处理
4. 构建和发布指导
